# Data Dictionary

| Field | Description |
|---|---|
| State/UTs | State or union territory label |
| Zone | Geographic zone |
| Total Cases | Recorded total cases |
| Active | Recorded active cases |
| Discharged | Recorded discharged/recovered cases |
| Deaths | Recorded deaths |
| Active Ratio | Active cases as % of total cases |
| Discharge Ratio | Discharged cases as % of total cases |
| Discharge Avg | Above/below average classification |
| Death Ratio | Deaths as % of total cases |
| Death Avg | Above/below average classification |
| Population | Population supplied by the dataset |

## Derived formulas

`Active Ratio = Active / Total Cases × 100`

`Discharge Ratio = Discharged / Total Cases × 100`

`Death Ratio = Deaths / Total Cases × 100`

Overall rates should be calculated from aggregated counts rather than by summing state-level percentages.
