# Screenshot Gallery

This folder is reserved for screenshots from the **actual Excel workbook**.

## Required files

1. `01-dashboard.png` — complete dashboard view.
2. `02-data-overview.png` — source Data sheet.
3. `03-pivot-analysis.png` — supporting pivot/summary analysis.
4. `04-analysis.png` — another meaningful analysis or chart.

## Screenshot rules

- Use real screenshots from the workbook.
- Keep numbers and labels readable.
- Crop out unrelated desktop content.
- Do not use mock or AI-generated dashboard screenshots.
